우리의 자산 — 배포 안내
============================

이 폴더 전체가 하나의 웹앱입니다. 서버 없이 동작하며, 데이터는
사용자의 기기(브라우저 localStorage)에 저장됩니다.

■ Netlify Drop 으로 올리기 (가장 쉬움)
--------------------------------------
1) 브라우저에서 https://app.netlify.com/drop 에 접속합니다.
   (Netlify 계정으로 로그인하면 사이트가 사라지지 않고 유지됩니다.)
2) 이 폴더('우리의자산')를 통째로 그 페이지 위로 드래그해서 놓습니다.
   ※ 폴더 안의 파일이 아니라 '폴더 자체'를 올려도 되고,
     폴더를 열어 안의 모든 파일(index.html, sw.js, manifest, 아이콘들)을
     한 번에 선택해 올려도 됩니다. index.html 이 반드시 최상위에 있어야 합니다.
3) 잠시 기다리면 https://랜덤이름.netlify.app 주소가 만들어집니다. 끝!
   원하면 Site settings → Change site name 에서 주소를 바꿀 수 있습니다.

■ 스마트폰 홈 화면에 앱처럼 설치하기 (PWA)
--------------------------------------
- 아이폰(사파리): 공유 버튼 → '홈 화면에 추가'
- 안드로이드(크롬): 메뉴(⋮) → '앱 설치' 또는 '홈 화면에 추가'
설치하면 주소창 없는 전체화면 앱으로 열리고, 오프라인에서도 실행됩니다.

■ 카카오 로그인 쓰려면 (선택)
--------------------------------------
카카오 로그인은 본인 카카오 앱의 'JavaScript 키'가 있어야 열립니다.
1) https://developers.kakao.com → 내 애플리케이션 → 앱 생성
2) [앱 키] 의 'JavaScript 키' 복사
3) [플랫폼] → Web → 사이트 도메인에 배포된 주소
   (예: https://우리의자산.netlify.app) 등록
4) [카카오 로그인] 활성화 ON, [동의항목]에서 '닉네임' 허용
5) 앱 로그인 화면의 '카카오로 시작하기' → 키 입력창에 JavaScript 키 붙여넣기
   (코드 수정 없이 앱 안에서 바로 입력됩니다.)
카카오 로그인을 쓰지 않아도 '게스트로 둘러보기' 또는 이메일 가입으로
모든 기능을 사용할 수 있습니다.


■ 이메일 로그인으로 여러 기기에서 같은 데이터 보기 (선택)
--------------------------------------
기본값은 기기별 저장(localStorage)이라 다른 폰에서는 데이터가 보이지 않습니다.
같은 이메일 계정으로 여러 기기에서 같은 데이터를 보려면 무료 Supabase 프로젝트를
연결하면 됩니다.
1) https://supabase.com 에서 무료 프로젝트를 만듭니다.
2) [Project Settings → API]에서 Project URL과 anon public 키를 복사합니다.
3) 앱 안에서: 메뉴 › 계정 › '이메일 로그인 · 클라우드 동기화 설정'을 열고
   위에서 복사한 URL과 키를 붙여넣어 저장합니다.
4) 같은 화면에 안내된 SQL을 Supabase [SQL Editor]에서 한 번 실행해 저장용
   테이블(user_data)을 만듭니다.
5) [Authentication → Providers → Email]에서 'Confirm email'을 꺼두면
   가입 즉시 로그인되고, 켜두면 가입 후 메일 인증 링크를 눌러야 합니다.
6) 이후 로그아웃 상태에서 이메일로 회원가입하면, 그 다음부터는 다른 폰에서도
   같은 이메일·비밀번호로 로그인해서 같은 데이터를 볼 수 있습니다.
   (설정 전에 만든 '이 기기 전용' 이메일 계정은 클라우드로 자동 이전되지
   않습니다. 새로 이메일로 가입해 클라우드 계정을 만들어 주세요.)
7) 메뉴 › 계정 화면에 동기화 상태가 표시됩니다('클라우드 동기화됨 · N분 전'
   등). 두 기기에서 비슷한 시점에 저장해 데이터가 엇갈리면 조용히 덮어쓰지
   않고 같은 화면에 '다른 기기에 최신 데이터가 있어요' 안내와 함께 어느
   쪽을 쓸지 고르는 버튼이 나타납니다.

■ 시세 자동 연동 (중요)
--------------------------------------
환율·금 시세는 앱이 직접 가져오고, 국내 주식은 'Netlify 함수'가 대신 가져옵니다.
(브라우저가 네이버 증권을 직접 부르면 보안정책(CORS)에 막히기 때문입니다.)

- 10분마다 자동 갱신됩니다. 메뉴 > '시세 자동 연동 (10분)'에서 끌 수 있습니다.
- 주식 시세가 나오려면 반드시 Netlify에 '폴더째' 올려야 합니다.
  (netlify/functions/stock.js 파일이 함께 올라가야 함)
- Netlify Drop 으로 처음 올릴 때 계정 로그인이 필요합니다(무료).
  로그인 없이 올리면 함수가 동작하지 않아 주식 시세만 갱신되지 않습니다.
- HTML 파일을 컴퓨터에서 그냥 열면(로컬) 시세 연동은 동작하지 않습니다. 정상입니다.
- 무료 한도(월 12만 5천 회)에 비해 사용량이 매우 적어(월 수천 회) 요금이 발생하지 않습니다.

■ 앱을 수정한 뒤 다시 올릴 때
--------------------------------------
index.html 등을 고쳤다면, sw.js 파일 맨 위의
  const CACHE = 'ourassets-v1';
에서 v1 → v2 처럼 숫자를 올린 뒤 폴더를 다시 Netlify Drop 에 올리면
사용자 기기에서 이전 캐시가 정리되고 최신본이 반영됩니다.

■ 참고
--------------------------------------
- 데이터는 기기별로 저장됩니다. 기기 간 동기화는 별도 백엔드 연결이 필요합니다.
- 앱 메뉴의 '내보내기'로 데이터를 백업할 수 있습니다.
